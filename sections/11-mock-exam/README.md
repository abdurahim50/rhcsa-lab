# Section 11: Full mock exam

**Status:** Not started · **Objectives covered:** all

A single three-hour exam that mixes tasks from every objective area, in no particular order and
without saying which objective each task belongs to. Graded after a reboot.

## Why this is separate

Practising one section at a time tells you whether you know that section. It does not rehearse
the thing that actually makes the exam hard:

- The real exam does not group tasks by topic, or tell you which skill a task is testing.
- Three hours of sustained work is a different test from 45 minutes.
- Tasks interact. A firewall rule from one task can break a service another task needs.
- Everything is graded after a reboot, all at once, at the end.

## Requirements

Both nodes, reverted to a clean snapshot. No notes, no internet, `man` and `/usr/share/doc` only.

## Prerequisites

Sections 01 to 10, each passed on a clean snapshot. Sit this only when they are all done.
