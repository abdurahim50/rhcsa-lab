# Section 06: Create and configure file systems

**Status:** Not started · **Objectives covered:** 5

## Objectives

- Create, mount, unmount, and use VFAT, ext4, and xfs file systems
- Mount and unmount network file systems using NFS
- Configure autofs
- Extend existing logical volumes
- Diagnose and correct file permission problems

## Lab requirements

Runs on node1 and its raw disks, plus node2 for the NFS exports.
