# Section 07: Deploy, configure, and maintain systems

**Status:** Not started · **Objectives covered:** 6

## Objectives

- Schedule tasks using `at`, `cron`, and systemd timer units
- Start and stop services and configure services to start automatically at boot
- Configure systems to boot into a specific target automatically
- Configure time service clients
- Install and update software packages from Red Hat Content Delivery Network, a remote repository, or from the local file system
- Modify the system bootloader

## Lab requirements

Runs on node1, plus node2 as the chrony time source and package repository.
